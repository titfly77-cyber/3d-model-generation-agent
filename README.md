# FORMA — AI 3D Design Agent

FORMA 是一个通过自然语言和参考图片创建 3D 资产的智能设计 Agent。用户只需要描述想要的物体，或上传一张参考图片，系统就会组织生成流程、调用图像与 3D 生成模型、自动处理模型文件，并在网页中提供可交互的预览和下载结果。

这个项目希望把传统的 3D 制作流程：

```text
创意 → 手工建模 → 材质制作 → 网格整理 → 渲染与导出
```

转变为由 Agent 协调的自动化流程：

```text
自然语言或参考图片
        ↓
需求理解与提示词优化
        ↓
三视图生成与参考图复核
        ↓
图像生成 3D
        ↓
Blender 自动处理与检查
        ↓
网页预览与多格式资产交付
```

## 项目能做什么

### 文字生成 3D

用户输入物体的外形、材质、颜色、风格和用途后，Agent 会先整理需求并生成适合三维重建的描述，再通过文生图模型制作同一物体的正面、侧面和背面参考图。通过布局和一致性检查后，三视图会被提交给图生 3D 模型完成重建。

当用户描述的是现实中可以明确识别的产品、载具、建筑或其他具体对象时，Agent 可以先检索公开图片并进行视觉核验。只有确认图片与目标对象准确对应后，图片才会作为生成参考；没有可靠参考时，系统会根据文字描述完成概念设计。

### 图片生成 3D

用户可以上传物体图片并直接进入图像重建流程。系统会处理图片方向、透明背景和尺寸，检查主体是否清晰可见，然后调用图生 3D 模型生成几何与纹理。

### Agent 工作流

项目使用有状态的 Agent 工作流组织整个生成过程。每个阶段都有明确输入、输出和检查结果，包括：

1. 理解用户需求并生成结构化设计说明。
2. 优化图像生成提示词。
3. 检索并核验可用的公开参考图片。
4. 生成或准备单图、三视图参考。
5. 检查主体完整性、视角顺序和跨视角一致性。
6. 调用云端图生 3D 服务生成模型候选。
7. 使用 Blender 自动整理网格、材质和场景。
8. 渲染多个检查视角并比较参考图与 3D 结果。
9. 选择质量更好的候选并交付最终资产。

工作流会保存阶段状态和中间结果。任务中断后可以从已经完成的阶段继续，避免重复执行已完成的生成步骤。

### 自动检查与人工决定

FORMA 会检查三视图分栏、主体完整性、视角一致性、模型文件完整性和基础几何有效性。视觉复核未通过时，系统可以自动重新生成候选，同时保留之前的结果用于比较。

自动检查用于发现明显问题，不替代人工验收。三视图未达到自动校验要求时，系统会暂停 3D 生成，并允许使用者选择重新生成参考图或接受风险继续重建。未经完整视觉确认的结果会标记为“待人工复核”。

### Blender 自动处理

生成的 3D 模型会进入 Blender 后处理流程，完成模型导入、基础网格检查、材质与纹理保留、场景整理、多角度检查渲染和格式导出。项目可以交付适合网页预览和后续编辑的多种 3D 文件格式。

### Web 3D 工作台

前端提供完整的生成与资产管理界面，用户可以：

- 创建文字生成 3D 或图片生成 3D 任务。
- 查看 Agent 当前阶段和执行轨迹。
- 查看生成使用的参考图与复核结果。
- 在浏览器中旋转、缩放和检查 3D 模型。
- 下载生成的模型与相关资产。
- 管理和删除本地资产记录。
- 配置可替换的语言模型、文生图模型和图生 3D 服务。

## 技术组成

- **Agent 编排：** LangGraph、LLM 结构化输出、状态检查点
- **后端服务：** Python、FastAPI、SQLite
- **图像生成：** 可替换的文生图模型与兼容 API
- **3D 生成：** 支持单图和多视图重建的云端 3D 模型服务
- **3D 处理：** Blender、Blender Python API、Trimesh
- **前端界面：** React、Three.js、WebGL
- **资产格式：** GLB、OBJ、STL、FBX、BLEND

## 设计原则

- **模型可替换：** 语言模型、文生图模型和图生 3D 服务通过统一配置接入。
- **过程可恢复：** 已完成步骤、中间参考图和模型候选会被保留，支持中断恢复。
- **结果可追踪：** 每个任务保存执行阶段、检查结果、候选版本和最终选择依据。
- **人机协作：** Agent 负责执行与检查，使用者保留对不确定结果的最终决定权。
- **保留原始资产：** 参考图片、生成候选和交付文件分开保存，便于复核和后续处理。
- **谨慎表达质量：** 自动评分用于候选比较，不被描述为真实测量精度或工程认证。

## 适用场景

- 游戏和互动应用中的道具原型
- 产品外观与工业设计概念验证
- 教学、实验和 Agent 工作流研究
- 展示模型与网页 3D 内容制作
- 3D 打印前期概念模型
- AR、VR 和数字内容资产原型

## 项目定位

FORMA 当前定位为 AI 3D 生成与 Agent 工作流实验项目。它重点探索自然语言理解、参考图生成、多视图重建、自动化 3D 处理和人工复核如何组合成完整的创作工具。

生成结果适合概念设计、快速原型和视觉实验。自动生成的模型不默认具备精确尺寸、机械装配、结构强度、封闭网格、打印壁厚或制造级拓扑保证，在用于生产、工程或 3D 打印之前仍需要专业人员检查和处理。
